Getting Started with Go2 ODD Observer

Setup and run ODD/COD analysis in minutes

📋 Prerequisites

Required

  • Python 3.10+ (tested on Python 3.10 with Ubuntu 22.04)
  • Google Gemini API Key - Get yours at Google AI Studio
    • Free tier includes 15 requests/minute
    • 1,500 free requests per day

Optional (for ROS2 data processing)

  • ROS2 Humble - Required only if processing new rosbag files
  • Unitree Go2 Robot - For collecting real-world data

🔧 Installation

1. Clone the Repository

git clone https://github.com/danmartinez78/go2-odd-observer.git
cd go2-odd-observer

2. Install Python Dependencies

# Create virtual environment (recommended)
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

Core dependencies installed: google-genai (Google ADK), python-dotenv, pandas, numpy, matplotlib, Pillow

3. Configure API Key

Option A: Environment Variable (Recommended)

export GOOGLE_API_KEY="your-api-key-here"

Option B: .env File

echo "GOOGLE_API_KEY=your-api-key-here" > .env

🎯 Quick Start: Run Your First Analysis

Option 1: Interactive Analysis

# Run the complete pipeline interactively
python scripts/run_odd_analysis.py

Select a scenario when prompted. The pipeline runs end-to-end and writes results to data/archive/analysis_results/.

Option 2: Batch Analysis

# Process multiple scenarios
python scripts/run_odd_batch_analysis.py

Batch runs aggregate summaries and archive per-scenario outputs.

Expected runtime: ~2 minutes for 2-window test sets

Generated Report Structure

{
  "report": {
    "compliance": {
      "status": "OUT_ODD",
      "confidence": "HIGH",
      "summary": "The verdict is OUT_ODD due to motion violations..."
    },
    "executive_summary": "The robot operated outside safety limits...",
    "key_findings": {
      "perception": "Indoor residential, low obstacle density",
      "motion": "Peak accel 12.6 m/s² exceeded 10 m/s² limit",
      "safety": "No humans/animals, 2 collision advisories"
    },
    "recommendations": ["Review motion control parameters"]
  },
  "analysis_metadata": {"scenario": "real_174321", "pipeline_version": "2.1.0"}
}

Compliance States

  • IN_ODD - Conditions within design parameters ✅
  • ODD_BOUNDARY - Near safety limits ⚠️
  • OUT_ODD - Exceeds operational envelope ❌

🛠️ Processing Your Own Data

Required ROS2 Topics

Topic Type Purpose
/robot0/odom nav_msgs/Odometry Wheel odometry
/robot0/imu sensor_msgs/Imu Inertial measurements
/robot0/front_cam/rgb sensor_msgs/Image RGB camera
/robot0/point_cloud2_L1 sensor_msgs/PointCloud2 LiDAR scan

Extract Windows from Rosbag

# Source ROS2 environment first
source /opt/ros/humble/setup.bash
source go2_ros2_sdk/install/setup.bash

# Extract with default parameters (2-second windows)
python scripts/extract_windows.py \
  --rosbag /path/to/your/bag.db3 \
  --output data/production/chunks/my_scenario \
  --run-id my_scenario
