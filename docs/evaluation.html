Evaluation & Testing

We use Google ADK’s evaluation framework plus hand‑picked scenarios to verify that each agent uses its tools correctly and produces grounded, useful outputs.

1. ADK Rubric Evaluations

Core evaluation entrypoint:

pytest tests/test_adk_evaluation.py -q

Key metrics (as defined by ADK):

  • rubric_based_tool_use_quality_v1 – checks that agents call the right tools with appropriate coverage.
  • rubric_based_final_response_quality_v1 – evaluates JSON shape, completeness, and clarity.
  • hallucinations_v1 – measures groundedness against provided context (enabled for loop agents and evaluator).

Detailed configuration and guidelines are documented in guides/AGENT_EVALUATION.md. Latest scores are recorded in tests/evaluation/RESULTS.md.

Scorecard (thresholds)

Agent Tool-use quality ≥ Final-response quality ≥ Hallucinations
Perception 0.70 0.70 Enabled
Motion 0.70 0.70 Enabled
Collision 0.70 0.70 Enabled
Evaluator 0.70 0.70 Relaxed (0.5) due to fixtures
Report 0.70 0.70 Disabled (function_call grounding limits)

Actual scores are logged per run in tests/evaluation/RESULTS.md; values above are target thresholds.

2. Scenario-Based Checks

  • Sim test scenarios – Known “clean” vs “collision” runs to sanity‑check ODD/COD behavior.
  • Real runs – Real Go2 logs used to check robustness to sensor artifacts and lighting changes.

These checks are run via scripts/run_odd_analysis.py (single scenario) and scripts/run_odd_batch_analysis.py (batch), with results archived under data/archive/analysis_results/.

Quick Start

This page summarizes the minimum steps to get the ODD Observer pipeline running locally. For deeper background, see docs/guides/GETTING_STARTED.md and the capstone report.

1. Prerequisites

  • Python 3.10+ and virtual environment (recommended).
  • Dependencies installed: pip install -r requirements.txt.
  • Valid Gemini API key exported (e.g., via .env or environment variable).

2. Single Scenario Run

From the repo root:

python scripts/run_odd_analysis.py

Select a scenario when prompted (e.g., a sim or real dataset). The script will run the full pipeline (ODD Spec → Perception/Motion/Collision → Evaluator → Report) and write results to data/archive/analysis_results/manual/<timestamp>/<scenario>/.

3. Batch Run

To run across a set of scenarios (e.g., all production data):

python scripts/run_odd_batch_analysis.py

Batch runs aggregate summaries and still archive per‑scenario results under data/archive/analysis_results/automated/.

4. Agent Evaluation

To run the ADK rubric‑based evaluation suite:

pytest tests/test_adk_evaluation.py -q

See guides/AGENT_EVALUATION.md for details on metrics and thresholds, and tests/evaluation/RESULTS.md for the latest scores.
