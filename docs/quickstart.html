Quick Start

This page summarizes the minimum steps to get the ODD Observer pipeline running locally. For deeper background, see docs/guides/GETTING_STARTED.md and the capstone report.

📌 Want to know which agent, tool, knowledge, and data versions you’re running? See Versioning.

1. Prerequisites

  • Python 3.10+ and virtual environment (recommended).
  • Dependencies installed: pip install -r requirements.txt.
  • Valid Gemini API key exported (e.g., via .env or environment variable).

2. Single Scenario Run

From the repo root:

python scripts/run_odd_analysis.py

Select a scenario when prompted (sim or real). The pipeline runs end‑to‑end and writes results to data/archive/analysis_results/manual/<timestamp>/<scenario>/.

3. Batch Run

To process multiple scenarios (e.g., all production datasets):

python scripts/run_odd_batch_analysis.py

Batch runs aggregate summaries and still archive per‑scenario outputs under data/archive/analysis_results/automated/.

4. Agent Evaluation

To run the ADK rubric‑based evaluation suite:

pytest tests/test_adk_evaluation.py -q

See guides/AGENT_EVALUATION.md for details on metrics and thresholds, and tests/evaluation/RESULTS.md for the latest scores.
