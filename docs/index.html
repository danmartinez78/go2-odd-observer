About This Project

The ODD Observer is an AI-powered analysis pipeline that monitors whether a robot is operating within its Operational Design Domain (ODD). Using a multi-agent system with Google Gemini models, it analyzes sensor data to detect violations and assess safety.

Key Features:

  • Multi-modal sensor fusion (camera, LiDAR, IMU)
  • Natural language ODD specification
  • Automated violation detection
  • Real-time risk assessment
  • Interactive HTML reports
  • Professional visualizations
  • Kaggle ADK Agent Capstone Project
  • Open source & extensible
