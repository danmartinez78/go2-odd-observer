Agents pass structured data via artifacts instead of context injection. Cleaner, more reliable pipeline.

Automatic sim vs real detection from sensor patterns. High confidence classification.

🤖 Agent Architecture

6 Specialized Agents
OddSpecAgent v6.1.0
Parses natural language ODD → structured spec
PerceptionAgent v7.4.0
Camera + LiDAR BEV analysis, data source detection
MotionAgent v7.3.0
IMU analysis, reasoning-based motion classification
CollisionAgent v7.3.0
Proximity assessment with ego vehicle awareness
EvaluatorAgent v5.0.0
COD construction + compliance verdict (gemini-2.5-pro)
ReportAgent v9.1.0
Executive summary + technical report generation

🔬 Technical Details

ODD Specification
  • Natural language → structured spec
  • Categorical axes (terrain, lighting, environment)
  • Numeric axes (acceleration, distance, velocity)
  • Boolean axes (collision, blocked path)
COD Construction
  • Per-window measurements
  • Type-driven aggregation
  • Semantic distance for categoricals
  • Fraction outside per axis
Compliance Verdict
  • IN_ODD / ODD_BOUNDARY / OUT_ODD
  • Confidence score (0-1)
  • Critical axes identification
  • Temporal stability (STABLE/MIXED/DEGRADING)
Models Used
  • gemini-2.5-flash - Sensor agents
  • gemini-2.5-pro - Evaluator (reasoning)
  • Vision-enabled for image analysis
  • ~$0.02/scenario (2 windows)
