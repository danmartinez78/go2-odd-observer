🚀 About This Project

The ODD Observer is an AI-powered multi-agent system that monitors whether a quadruped robot operates within its Operational Design Domain (ODD). Built with Google's Agentic Development Kit (ADK) and Gemini models, it provides real-time safety analysis from multimodal sensor data.

🎯 System Capabilities:

Reasoning-Based Motion Detection
  • Evidence hierarchy: Camera vision > Temporal patterns > Gyroscope > Accelerometer
  • Gravity compensation for stationary detection
  • Complex motion pattern analysis
Spatial Perception
  • BEV scale awareness (0.05 m/pixel)
  • Robot body exclusion for accurate distance measurement
  • Multimodal sensor fusion (camera + LiDAR)
Ego Vehicle Specification
  • ISO 34503 compliant vehicle dimensions
  • 0.65m × 0.31m × 0.4m (L×W×H)
  • Clearance requirements (0.4m min, 0.5m comfortable)
ODD Parameters
  • Acceleration: 10.0 m/s² max (5.0-10.0 boundary zone)
  • Collision risk: 0.75 IN_ODD (0.75-0.9 boundary)
  • Motion types: smooth, complex, abrupt

🔬 Technical Innovation:

Sensor Fusion
  • Camera + LiDAR BEV analysis (gemini-2.5-pro)
  • IMU-based motion with jerk detection
  • Visual odometry for velocity estimation
  • Odometry-independent (works with real robots)
Multi-Agent Pipeline
  • 8 specialized agents (perception, motion, collision, etc.)
  • Natural language ODD specification
  • Automated COD classification
  • ODD compliance with violation detection

✨ Key Features:

  • Reasoning-Based Motion - Camera evidence > IMU artifacts (gravity compensation)
  • Spatial Perception - BEV scale (0.05 m/pixel) + robot body awareness
  • Ego Vehicle Specs - ISO 34503 compliant (0.31m width, 0.4m min gap)
  • Multi-Modal Fusion - Camera + LiDAR + IMU with cross-validation
  • Interactive Reports - Plotly charts & dark mode
  • Real Robot Testing - Unitree Go2 with broken odometry
  • ODD Boundaries - 10 m/s² accel, 0.75 collision risk
  • Production Ready - 7 real + 1 sim scenarios validated
