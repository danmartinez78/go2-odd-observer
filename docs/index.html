📐 What is ODD & COD?

🎯 ODD - Operational Design Domain

The ODD defines the safe operating envelope for a robot—the conditions under which it's designed to function correctly.

  • Environmental: Lighting (bright/dim), terrain (smooth/rough), indoor/outdoor
  • Dynamic: Max speed, acceleration, pitch/roll limits
  • Safety: Obstacle density, collision avoidance boundaries
📊 COD - Current Operating Domain

The COD captures what actually happened during robot operation—the observed conditions across all ODD axes.

  • Per-window measurements: What was observed in each time window
  • Region construction: Aggregated operational envelope
  • Compliance check: Is COD ⊆ ODD? (COD contained within ODD)
Verdict: IN_ODD COD fully within ODD | BOUNDARY COD at or near edge of ODD | OUT_ODD COD exceeds ODD limits

🧠 Agent Reasoning Capabilities

👁️ Visual Grounding

Agents analyze camera images and LiDAR BEV (Bird's Eye View) maps to make observations grounded in actual sensor data.

  • Height, occupancy, roughness BEV channels
  • Obstacle detection and classification
  • Environment type inference
📊 Temporal Reasoning

Cross-window analysis identifies patterns, trends, and anomalies that single-frame analysis would miss.

  • Stability assessment across windows
  • Transition detection (STABLE→DEGRADING)
  • Trend identification in motion profiles
🏷️ Semantic Understanding

Categorical axes use semantic distance for nuanced compliance—"indoor_commercial" ≈ "commercial" with low penalty.

  • Fuzzy matching for environment types
  • Context-aware terrain classification
  • Semantic distance in COD construction
🔗 Chain of Thought

Each agent provides explicit reasoning chains that explain why observations lead to conclusions. Fully auditable.

⚡ ODD-Aware Filtering

Agents receive the ODD spec and intelligently focus observations on relevant axes, reducing noise and improving accuracy.

🔬 Technical Details

ODD Specification
  • Natural language → structured spec
  • Categorical axes (terrain, lighting, environment)
  • Numeric axes (acceleration, distance, velocity)
  • Boolean axes (collision, blocked path)
COD Construction
  • Per-window measurements
  • Type-driven aggregation
  • Semantic distance for categoricals
  • Fraction outside per axis
Compliance Verdict
  • IN_ODD / ODD_BOUNDARY / OUT_ODD
  • Confidence score (0-1)
  • Critical axes identification
  • Temporal stability (STABLE/MIXED/DEGRADING)
