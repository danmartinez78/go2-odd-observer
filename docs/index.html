🚀 About This Project

The ODD Observer is an AI-powered multi-agent system that monitors whether a quadruped robot operates within its Operational Design Domain (ODD). Built with Google's Agentic Development Kit (ADK) and Gemini models, it provides real-time safety analysis from multimodal sensor data.

� Refined ODD System v2.0 - Major Improvements:

✨ November 2025 Update: Breakthrough in Motion Detection & Spatial Perception
1. Reasoning-Based Motion Detection
  • Problem: Stationary robot detected as "moving" (IMU gravity leakage: 0.43 m/s² from 1.3° tilt)
  • Solution: Evidence hierarchy - Camera vision > IMU accelerometer
  • Result: 100% accuracy on stationary scenarios, 0% false positives
2. Spatial Perception Enhancement
  • Problem: Distance errors (0.6m reported, actual 1.0-1.5m)
  • Solution: BEV scale information (0.05 m/pixel) + robot body exclusion
  • Result: Accurate distance estimates (0.75-1.58m)
3. Centralized Ego Vehicle Specs
  • Problem: Poor traversability (0.45) despite 96% free space
  • Solution: Mandatory ego_vehicle in ODD (ISO 34503 compliant)
  • Result: Size-aware assessment (0.7-0.9 traversability)
4. Refined ODD Boundaries
  • Acceleration: 2.0 → 10.0 m/s² (agile maneuvering)
  • Collision Risk: 0.5 → 0.75 (closer proximity OK)
  • Motion: Added "abrupt" for reactive obstacle avoidance

Impact: Scenario real_06_174604 improved from OUT_ODD (false alarm) → IN_ODD (correct), demonstrating system can now distinguish safe operation from actual violations. See LESSONS_LEARNED.md for full technical details.
