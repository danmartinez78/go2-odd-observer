🚀 About This Project

The ODD Observer is an AI-powered multi-agent system that monitors whether a quadruped robot operates within its Operational Design Domain (ODD). Built with Google's Agentic Development Kit (ADK) and Gemini models, it provides real-time safety analysis from multimodal sensor data.

🔬 Technical Innovation:

Sensor Fusion
  • Camera + LiDAR BEV analysis (gemini-2.5-pro)
  • IMU-based motion with jerk detection
  • Visual odometry for velocity estimation
  • Odometry-independent (works with real robots)
Multi-Agent Pipeline
  • 8 specialized agents (perception, motion, collision, etc.)
  • Natural language ODD specification
  • Automated COD classification
  • ODD compliance with violation detection

✨ Key Features:

  • Motion Smoothness Analysis - Jerk-based abrupt motion detection
  • Terrain Classification - Distinguishes surface vs elevation
  • Real Robot Validation - Tested on Unitree Go2
  • Data-Driven Thresholds - 5.0 m/s² from 100 production windows
  • Interactive Reports - Plotly charts & dark mode
  • Aggregate Dashboard - Batch analysis visualization
  • Professional Documentation - Comprehensive guides
  • Kaggle ADK Capstone - Competition submission
🎯 Real-World Impact: This system detected 4 critical violations in the demo scenario: abrupt emergency stop motion (jerk-based), blocked path (traversability: 0.0), critical collision risk (0.9), and acceleration spike (5.69 m/s²). The robot correctly identified unsafe operating conditions.
