# Data Directory

Organized storage for all project data: raw inputs, processed outputs, test fixtures, and development artifacts.

---

## 📁 Directory Structure

```
data/
├── raw_rosbags/           # ROS2 bag files (input data)
│   ├── real/              # Real robot deployments
│   └── sim/               # Simulation runs
├── production/            # Production processed data (batch runs)
│   ├── sim_1_0/           # Sim scenario 1, version 0
│   ├── real_01_v1/        # Real scenario 01, version 1
│   └── ...
├── test/                  # Test fixtures and sample data
│   ├── real_01_173442/    # Real robot test scenario 1
│   ├── real_02_173813/    # Real robot test scenario 2
│   ├── sim/               # Sim test scenarios
│   └── images/            # Test images for unit tests
├── development/           # Development artifacts
│   └── bagfile_audit/     # Phase 0 bagfile investigation
├── archive/               # Archived data (reference only)
│   └── analysis_results/  # Old analysis reports
└── examples/              # Demo outputs for documentation
    ├── demo_analysis_report.json
    └── demo_executive_summary.json
```

## 📊 Data Organization

### `raw_rosbags/` - Input Data

**Purpose**: Raw ROS2 bag files from robot deployments.

**Structure**:
- `real/` - Physical robot data
- `sim/` - Simulation data

**Note**: These files are large and gitignored. Not included in repository.

**Expected topics**:
- `/robot0/cmd_vel` - Command velocities
- `/robot0/odom` - Odometry
- `/robot0/imu` - IMU data
- `/robot0/front_cam/rgb` - Camera
- `/robot0/point_cloud2_L1` - LiDAR

---

### `production/` - Production Processed Data

**Purpose**: Time-windowed multi-modal data extracted from rosbags for batch analysis.

**Generated by**: `scripts/extract_windows.py`

**Structure per scenario**:
```
production/my_scenario_v1/
├── index_my_scenario_v1.csv           # Window metadata
├── motion_my_scenario_v1_w000.json    # Motion time series
├── cam_my_scenario_v1_w000.png        # Camera frame
├── bev_occupancy_my_scenario_v1_w000.png  # LiDAR BEV (cropped)
├── bev_height_my_scenario_v1_w000.png     # Height map
├── bev_density_my_scenario_v1_w000.png    # Density map
├── bev_roughness_my_scenario_v1_w000.png  # Roughness map
└── ...
```

**Naming convention**: `{source}_{id}_v{version}`
- `sim_1_v0` - Sim scenario 1, version 0
- `real_01_v2` - Real scenario 01, version 2

**Version tracking**: See `data/DATA_VERSIONS.md` for changelog

**Retention**: Gitignored (regenerable from raw rosbags).

---

### `test/` - Test Data

**Purpose**: Small, curated datasets for manual testing during development and unit tests.

**Subdirectories**:

#### `test/real_XX_XXXXXX/`
Real robot test scenarios (2 windows each):
- Standardized test sets from representative deployments
- Used for manual agent testing and validation
- Regenerable with `scripts/regenerate_test_data.sh`

#### `test/sim/`
Sim test scenarios (6 windows):
- Multiple time points from simulation runs
- Used for testing BEV transformations and agent behavior

#### `test/images/`
Unit test fixtures:
- Various sizes and formats
- Different lighting conditions
- Edge cases (blank, corrupted, etc.)

**Usage**:
```python
from pathlib import Path

TEST_DATA = Path("data/test/sim")
scenario_index = TEST_DATA / "index_sim.csv"
```

**Retention**: Small enough to version control metadata, images gitignored.

---

### `development/` - Development Artifacts

**Purpose**: Temporary outputs during development and debugging.

**Subdirectories**:

#### `development/debug_frames/`
Debug image outputs from extraction/rendering:
- Frame-by-frame extractions
- Intermediate processing steps
- Visualization outputs

**Note**: These are gitignored and safe to delete.

## 📝 File Naming Conventions

### Motion Files
`motion_{scenario}_{window}.json`
- Example: `motion_sim_run_new_w003.json`

### Image Files
`{type}_{scenario}_{window}.png`
- Camera: `cam_sim_run_new_w003.png`
- BEV: `bev_occupancy_sim_run_new_w003.png`

### Index Files
`index_{scenario}.csv`
- Contains: window_id, start_time, end_time, file paths

### Reports
`odd_analysis_report.json`
- One per scenario directory

## 🗑️ Cleanup Commands

```bash
# Remove all debug frames
rm -rf data/development/debug_frames/*

# Remove processed runs (keep manifest)
rm -rf data/processed/runs/*/
# (Regenerate with: python scripts/extract_windows.py)

# Remove generated demo data
rm -rf data/processed/runs/demo_run/
# (Regenerate with: python scripts/generate_demo_data.py)
```

## 💾 Backup Recommendations

**Critical** (backup regularly):
- `raw_rosbags/real/` - Irreplaceable real robot data
- `processed/manifest.csv` - Scenario metadata

**Regenerable** (can be recreated):
- `processed/runs/` - From raw rosbags
- `development/` - Debug outputs
- `test/` - Fixtures in version control

---

## 📊 Storage Guidelines

**Typical sizes**:
- ROS2 bag: 100 MB - 10 GB per run
- Processed scenario: 10-50 MB (depends on window count)
- Debug frames: 20-100 MB (temporary)

**Cleanup schedule**:
- Debug frames: Delete after debugging session
- Old processed runs: Archive after 30 days if not in use
- Raw rosbags: Archive to external storage after processing
